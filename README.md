📖 Conversor de Moedas

📌 Sobre

Este projeto foi desenvolvido como parte de estudos de lógica de programação e consumo de APIs utilizando Java.
Ele realiza a conversão de valores monetários em tempo real através da ExchangeRate-API.
A aplicação roda diretamente no console, exibindo um menu interativo com 6 opções de conversão pré-definidas e encerrando após cada operação.

⚙️ Funcionalidades

Menu interativo no console com 6 opções de conversão:

Dólar ↔ Peso argentino
Dólar ↔ Real brasileiro
Dólar ↔ Peso colombiano

Consulta a valores atualizados diretamente da API.

Aceita valores com vírgula ou ponto (ex.: 123,45 ou 123.45).

Trata erros de entrada inválida e de conexão com a API.

Encerra automaticamente após a conversão.
